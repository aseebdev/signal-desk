SignalDesk frequently asked questions

What is SignalDesk?

SignalDesk is a personal action workspace designed to help organize and prioritize obligations, follow-ups, ideas, and decisions.

Is SignalDesk a traditional to-do list?

It goes beyond a simple checklist by attaching impact, effort, timing, category, and context to each signal and using those inputs to produce a transparent priority score.

Does SignalDesk require an AI API key?

No. SignalDesk does not pretend deterministic rules are AI. Its current prioritization engine is transparent and works without an external AI provider.

Where is SignalDesk data stored?

The workspace uses browser local storage. The minimal name-and-age entry record is processed by the app API; local development writes it to data/users.log.

Only name + age are sent to the local Node server and appended to data/users.log.
